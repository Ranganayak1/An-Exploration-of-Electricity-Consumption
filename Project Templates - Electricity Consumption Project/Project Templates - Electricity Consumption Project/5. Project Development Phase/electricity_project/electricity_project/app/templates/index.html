India Electricity Consumption Analytics

State-wise electricity usage analysis, January 2019 – December 2020, covering the COVID-19 nationwide lockdown period.

About this project

Electricity is a vital driver of economic activity, reflecting both industrial productivity and household energy access. This project analyzes state-wise electricity consumption across India from January 2019 to December 2020 — a period that includes the nationwide COVID-19 lockdown (March–June 2020) — to understand how national and regional demand shifted, and how different states recovered afterward.

  • Data Integration: state-wise monthly consumption loaded into a SQL database
  • SQL Analysis: trend, regional, and recovery queries (see sql/queries.sql)
  • Visualization: interactive charts covering all three scenarios
  • Dashboard: filterable, responsive analytics dashboard
  • Story: a 3-scene narrative walkthrough of the pandemic's energy impact
  • Web Integration: dashboard and story embedded in this Flask app

Three scenarios explored

1. Overall Consumption Trends

National month-by-month usage, Jan 2019 – Dec 2020, vs. seasonal & lockdown effects.

2. Regional Variations in Demand

Northern, Southern, Eastern, Western & Northeastern states compared.

3. Recovery After Lockdown

Which states bounced back fastest between mid- and end-2020.
